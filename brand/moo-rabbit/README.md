# Moo Rabbit（兔比）｜MOOTECH cms_system 事業部吉祥物

兔比是 MOOTECH **cms_system 事業部**的吉祥物，和集團吉祥物「熊北（Mootech Bear）」同一個世界觀、同一套配件與渲染質感。
熊北代表網路服務「厚實可靠、全天候守護」；兔比代表 CMS 網站系統「靈巧快速、一鍵換膚、多語系上線」。

## 使用原則（沿用熊北）

1. **少量、有目的**：一個頁面最多 2～3 處出現兔比（不含右下角客服）。
2. **不擋內容**：不可蓋住標題、內文、按鈕；手機版優先縮小或省略。
3. **動態要輕**：浮動、眨眼、耳朵輕晃即可；大動作只用在主視覺影片與活動。
4. **一致性**：配件不可缺少或換色；生成新圖時一律附上四視圖當參考。
5. **語系**：對外素材不得出現中文；需要文字時只用英文／韓文／泰文。
