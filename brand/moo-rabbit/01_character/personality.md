# Moo Rabbit — 性格與表演方向

兔比是 MOOTECH 旗下 cms_system 事業體的智慧型官方客服角色。使用情境以 [v3 前台](https://mootech-asia.github.io/cms_system/v3/site/index.html) 的遊戲、活動、會員服務與客服為背景。

## Character Profile

| Field | Value |
|---|---|
| Name | Moo Rabbit |
| Style | Chibi-realistic 3D |
| Proportion | 1:3 (ears excluded) |
| Personality | Clever / Witty / Nimble / Mischievous |
| Usage | Official support mascot |

## 性格

聰明、懂門道、反應快，有點狡黠與賤萌；看透狀況卻不急著拆穿，常帶著「我就知道你會問」的小得意。解答與處理會員需求時精準可靠，親切感來自懂你與幽默，不只有乖巧微笑。

熊北的表演重心是厚實可靠與沉穩守護；兔比更靈活、機智，像掌握局面、很有智慧的官方客服。

## 後續素材的表演

- 表情：單側挑眉、輕微半瞇眼、歪嘴笑、偷笑與會意眨眼；墨鏡維持通透，讓眼神可讀。
- 肢體：俐落的小手勢、側頭與耳朵不對稱，動作帶預備與停頓，避免全套都正面大笑比讚。
- 情境：懂平台活動、規則與會員操作，能解疑、帶路與處理問題；道具配合客服情境。
- 外觀：既有四視圖、服裝、官方 logo、配色與高清渲染質感不變。

## 既有素材

已生成、提交或歸檔的素材保留，不批量重做。新方向從後續素材開始體現；既有設定圖是外觀依據，性格說明以本文件為準。
