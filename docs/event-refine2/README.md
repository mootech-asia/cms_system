## 功能與視覺分開驗證

- `regression.json`：兩活動 × en/ko/th × 390/1440，另360首屏控制；空資料、零次數、被拒絕的儲存／剪貼簿、resolver錯誤、WebGL備援。
- `folio.json`：兩活動 × en/ko/th × 360/1440，六筆舊紀錄與新增紀錄、分享、靜音、焦點返回與44px控制。
- `scenes.json`：環境動態、減少動態、離屏、旋轉手指、開蓋及多寶物。
- `swipe.json`：向上開啟；向下、水平、太短手勢不開啟；WebGL與2D備援。
- `final-interactions.json`：20包序號繞回、音樂第一次操作後載入、循環、靜音恢復、開獎降音量與還原。visibility以派發事件測試handler，非實機切換App。
- 視覺證據：真實390px截圖與帶時間戳的CDP錄影；另外檢視360與1440的三語規則／紀錄。
- 真實 iOS/Android、原生分享App、實機音訊輸出與CMS正式獎品API未驗證。活動獎項與次數仍使用既有mock或外部注入，未新增後台。
