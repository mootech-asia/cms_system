## 二、Event：兩款轉盤

### 1. 網址與入口（Spec 頁）

| 活動 | 獨立網址 | 社群分享圖（og:image，1200×630） |
|---|---|---|
| Lucky Wheel（百老匯） | https://mootech-asia.github.io/cms_system/event/20261111_lucky_wheel/ | `event/20261111_lucky_wheel/assets/img/share-preview.jpg` |
| Survival Spin（生存） | https://mootech-asia.github.io/cms_system/event/20261111_survival_spin/ | `event/20261111_survival_spin/img/share-preview.jpg`（美術新交付：生存主標＋桃紅轉盤＋面具人物比讚＋墨綠階梯大廳） |

- 生存輪盤不再是「Lucky Wheel 加 `?skin=survival`」，而是自己的目錄與入口頁，社群平台抓得到自己的分享圖。

### 2. 進站 Loading（新增 Frame：Event / Loading，兩款皮各一）

| 元素 | 規格 |
|---|---|
| 整頁遮罩 | 全螢幕，底色＝該皮 `backdrop`（百老匯 `#2B140A`、生存 `#06231F`），z 最上層 |
| 內容區 | 寬 min(70vw, 260)，置中 |
| 標題 | 「Loading…」（ko「로딩 중…」、th「กำลังโหลด…」）16px／800／白，下距 12 |
| 進度條 | 高 10，膠囊，底 `rgb(255 255 255 / 18%)`；填滿條為 `primary → primary-2` 水平漸層（百老匯 `#E5484D→#FF8A3D`、生存 `#E8327C→#FF6FA8`） |
| 百分比 | 「0%」13px／700／白 85%，上距 8 |
| 行為 | 該皮所有圖（舞台、介面件、吉祥物全部狀態、獎項圖示）載完才消失；進度＝已載入張數比例 |

- 首次進入剩餘次數顯示 **10**（原 3）。

## 六、BO 後台：平台管理 → 權限設置（Bo_system 檔新增）

> 版型、色票、字體全部沿用 BO 既有「平台管理 → 用戶設置」頁的樣式（深色面板 `pan1→pan2` 漸層、1px `bd` 邊框、切角、青色 `acc1` 強調）。側欄「平台管理」子項最後一個新增「權限設置」；進入後頂部兩個分頁：**用戶管理**／**角色管理**。

### 1. 用戶管理（頁）

| 區塊 | 內容 |
|---|---|
| 搜尋面板 | 三欄：用戶名稱（輸入）、手機號碼（輸入）、狀態（下拉：全部／正常／停用）；右下「重置」（描邊鈕）＋「搜索」（實心青鈕，含放大鏡） |
| 工具列 | 右上「刷新」（描邊）、「新增」（青色描邊＋「＋」） |
| 表格欄位 | 編號、登入名、暱稱、手機號、電子郵件、角色、狀態（開關，正常／停用）、建立時間、操作（修改｜重設密碼｜刪除；admin 無刪除） |
| 表尾 | 「總計 N 條」 |
| 空狀態 | 「沒有數據」＋文件圖示 |

### 2. 角色管理（頁）

| 區塊 | 內容 |
|---|---|
| 搜尋面板 | 角色名稱、權限字符、狀態（全部／正常／停用）；重置／搜索 |
| 工具列 | 刷新、新增 |
| 表格欄位 | 編碼、角色名稱、權限字符、顯示順序、狀態（開關）、建立時間、備註、操作（修改｜刪除；admin 無刪除） |

### 3. 彈窗（Dialog Component ×4）

| 彈窗 | 寬 | 內容 |
|---|---|---|
| 添加用戶／修改用戶 | 720 | 兩欄表單：＊用戶暱稱、＊手機號碼、＊電子郵件、＊用戶名稱、＊用戶密碼、用戶性別（請選擇／男／女／未知）、狀態（正常／停用）、＊角色（下拉，列出啟用中的角色）、備註（整行 textarea）。頁尾「取 消」「確 定」 |
| 重設密碼 | 480 | 用戶名稱（唯讀）、＊新密碼、＊確認密碼 |
| 添加角色／修改角色 | 640 | ＊角色名稱、＊權限字符、＊角色順序（數字，寬 120）、狀態、**選單權限**（樹狀勾選框：最上面「全選」，其下每個側欄群組一列＋子頁面在下一列橫向排列；父項全勾＝勾、部分＝半填）、備註 |
| 確認刪除 | 440 | 紅色「!」標、「刪除後無法復原，確定要刪除「名稱」嗎？」、「取 消」「刪 除」（紅底） |

### 4. 選單權限樹的節點（依 BO 側欄自動生成）

儀表板｜平台管理（用戶設置、平台設置、供應商設置、遊戲管理、域名管理、操作紀錄、權限設置）｜玩家支付管理（存款、提現、調整）｜流水管理（總流水、玩家遊戲統計、真人娛樂、老虎機/釣魚、體育、PVP、小遊戲）｜排行榜（VIP 等級設置、VIP 等級列表、等級歷史）｜促銷管理（促銷橫幅管理、存款促銷、投注促銷、活動促銷、登入簽到、推薦系統、紅利記錄查詢）｜公告管理（公告）｜報告（所有盈虧 KPI、活躍會員、遊戲場所市場分析、遊戲場所表現、玩家分析、遊戲玩家分析、遊戲收入分析、遊戲分析）｜合作夥伴管理（合作夥伴賬戶、合作夥伴運營、合作夥伴佣金、會員對應代理調整、代理提現）

### 5. 刻意不做的（對照 INFA）

- 用戶管理左側的部門樹、添加用戶的「歸屬部門」欄位。
- INFA 的「選單管理」頁與角色權限裡「選單管理（新增／修改／查詢／刪除選單）」那一組。

### 6. 三語

介面文字有 en／ko／th 字典（例：權限設置＝Permission settings／권한 설정／ตั้งค่าสิทธิ์；用戶管理＝User management；角色管理＝Role management；重設密碼＝Reset password；選單權限＝Menu permissions；全選＝Select all）。
