## 驗證結果

- `verify-unbox-art.cjs`：兩款 × en/ko/th × 390/1440，共 12 次開獎／收藏流程；另測 360×640 按鈕、儲存／剪貼簿拒絕、空資料、零次數、resolver 錯誤回復、WebGL 降級。見 gameplay.json。
- `verify-unbox-folio.cjs`：兩款 × 三語 × 360/1440，共 12 組；分享／音效／焦點還原、舊紀錄圖示、7 筆紀錄、44px 點擊範圍。見 folio.json。
- `verify-unbox-polish.cjs`：兩款六個位置皆可用滑鼠點選，三語主標保持正確。見 interactions.json。第一次與數個 SwiftShader 瀏覽器同跑時逾時，隔離重跑通過；不把並行軟體 GPU 負載當成產品已修正的缺陷。
- `verify-unbox-scenes.cjs`：動態／減少動態／離屏暫停、180° 手勢、寶箱蓋開啟影格、三件實體寶物及揭曉中換語言。見 scenes.json。
- `check-event-loading.cjs`：兩轉盤三語、動畫下載失敗保留 poster、關鍵圖卡住仍釋放載入層。見 wheel-loading.txt。
- `check-event-split.cjs`：兩轉盤三語 × 390/1440，分享及開獎；3 種舊網址轉址與社群 metadata。見 wheel-flows.json。

## 效能量測條件

`check-event-performance.cjs`：本機 HTTP 靜態伺服器、Chromium SwiftShader、390×844、冷快取、CPU 6 倍降速、1.6 Mbps／150ms；資源 bytes 是載入層消失時已完成的 encodedBodySize，不含尚未完成的背景預載。rAF 間隔不等於 WebGL 實際 FPS；3D 主動限制 30fps。每個活動都在同樣限制下實際開到結果畫面。

| 活動 | 進站至可操作 | 2 秒待機主執行緒耗時 | 已完成資源 bytes |
|---|---:|---:|---:|
| 宇宙卡包 | 10.54 秒 | 853 ms | 1,807,498 |
| 沙漠寶箱 | 9.60 秒 | 649 ms | 1,697,468 |
| 幸運轉盤 | 4.07 秒 | 1,118 ms | 563,183 |
| 生存轉盤 | 3.69 秒 | 1,254 ms | 497,626 |

兩款 3D 活動以 draw call 計數驗證離屏後停止 WebGL 繪製，返回後仍可開獎。測量不代表實機保證，也不宣稱固定速度提升百分比。本機伺服器無 HTTP 壓縮，部署 CDN 傳輸條件不同。

未驗證：實體 iOS／Android 的 GPU、耗電與喇叭輸出；正式會員／後台派獎。這些頁面仍是 mock 活動，沒有改動獎率或正式派獎。
