# 手機活動場景與文字修正

## 需求與修改
- 「手機版本需要優化」：短 CMS iframe 原本把場景壓到約 178px，現有依寬度計算的最低高度（375px 寬時約 327px），保留垂直捲動。角色在舞台內調整尺寸；選定寶箱時讓開啟按鈕進入視窗。支援收合的客服入口預設收起，v3/site 補上收合入口。
- 「寶箱沒有在地板」：暖色接觸陰影貼合箱底，降低外圈影子強度，投影往光源反方向延伸。修正手機比例後箱體與沙地接觸位置可辨認。
- 「文字因為陰影不清楚請優化」：次數及主操作文字移除模糊陰影、數字加粗；短視窗次數框加寬以容納泰文。

## 驗證
- `npm run build` 成功。
- `scripts/verify-event-mobile.cjs`：卡包／盲盒各 5 個手機尺寸（320–414px），無橫向溢出、場景最低尺寸、盲盒選定／開啟／領取流程、文字陰影。8 個 CMS 嵌入入口檢查。
- `scripts/verify-unbox-layout.cjs`：12 個視窗／語系／嵌入組合，挑選和選定狀態共用介面位置比對通過；隱藏箭頭的零尺寸座標不加入捲動偏移。
- 320px 泰文、375px 英文及 CMS 實際渲染截圖附於此目錄。青色邊線為鍵盤選定測試的焦點提示。
- v2/site 與 v2/site-mobile 保留原有客服列；畫面未遮住開啟按鈕。其他有收合入口的頁面驗證展開／收合。

## 限制
Chromium 行動裝置模擬與軟體 WebGL，未做真實 iOS／Android GPU、慢網路及全站登入／skin 流程驗證。本次沒有更換圖片或動畫素材。
