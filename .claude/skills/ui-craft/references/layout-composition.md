# 版面構成——同樣內容排得不一樣

這份補的是「視覺排列」跟「變化性」：前面幾層講的是單一元件/色彩怎麼做對，這份講的
是**整個區塊/整頁的版面骨架**怎麼避免每次都長一樣——永遠置中、永遠等寬分欄、永遠
一樣的卡片網格，是這個 repo（或任何 AI 產出的介面）最容易被看出來「套公式」的地方。

## 四種打破「永遠等寬置中網格」的手法

這些手法彼此獨立，不用全部用上，第二層「突破」已經講過「一個頁面/區塊只做一個
記憶點」——下面四種可以當作記憶點的候選清單，挑一個跟這次內容最搭的，不是每個都塞：

1. **不對稱分欄**：不是每次都切成相等寬度的 2/3/4 欄。例如 7 欄網格裡讓內容佔
   3+4（而不是對半的 3.5+3.5），或兩欄裡一欄是另一欄的兩倍寬。適合「一個主要內容
   配一個次要內容」的區塊（例如活動說明 + 條款備註、遊戲介紹 + 規則連結），主次
   關係用欄寬直接表達，而不是兩欄一樣寬再靠文字量自然撐開。
2. **尺寸對比**：一個小標籤/說明文字緊貼著一個明顯放大的數字或標題（例如促銷頁的
   倍數/金額用遠大於周圍文字的字級呈現，說明文字維持正常大小）。這是第一層
   Hierarchy 原則的延伸，但特別指「刻意拉開同一區塊內兩個元素的字級差距」，而不是
   讓所有文字都落在中間尺寸。
3. **留白集中而非均攤**：不是每個區塊都用一樣的內距把內容往中間擠，而是刻意讓某個
   區塊的留白大量集中在一側/一角，內容靠邊放。適合整頁留白感不足、每個區塊都一樣
   擁擠的情況——不是到處加留白，是把留白集中到一個地方更顯眼。
4. **跨界溢出**：元素刻意超出容器邊界，呼應 `techniques.md` 已經提過的 overlap
   手法（負 margin 讓卡片跨兩個背景區塊），這裡再加一種：單一視覺元素（大圖示、
   裝飾性數字、品牌圖案）局部超出自己容器的邊界線，製造「這個元素比版面本身還要
   大」的張力，而不是每個元素都乖乖待在自己的格子裡。

## 變化性稽核：同一頁/同一版本裡，區塊長得太像了嗎？

這是對「變化性」的具體檢查，不是只靠感覺：

- 列出同一頁面（或同一版本的多個頁面）裡用到「卡片/區塊」構成的地方，確認不是每
  一個都用同樣的等寬網格+同樣內距+同樣圓角——如果超過三個區塊長得一模一樣（只是
  內容不同），代表這裡在套公式，該用上面四種手法之一打破至少一兩個。
- 不是每個區塊都要打破——首頁第一個區塊（hero）適合用尺寸對比或跨界溢出建立
  記憶點，後面平鋪陳列的功能列表/遊戲列表維持規整的等寬網格反而是對的（這類內容
  本身就是要讓使用者快速掃過比較，規整比花俏更好用）。判斷標準是**這個區塊的內容
  性質適不適合被打破**，不是「為了變化而變化」。
- 這些手法一律只用既有的 grid/flex CSS 加既有間距 token 達成，不需要新顏色、新
  字型、新圖片素材——跟第一層「既有優先」的原則完全相容。

## 跟既有章節的關係

- 這份是「版面骨架」層級的變化，第二層「突破」的記憶點可以**是**這四種手法之一，
  但記憶點也可以是動效/深度/色階層次這類非版面的手法（見
  `craft-polish-motion.md`）——不要誤以為只有打破網格才算記憶點。
- 不對稱分欄/留白集中改動到結構時，記得同步跑一次第五層「多語言排版」的檢查：
  不對稱分欄裡比較窄的那一欄，換成韓文/泰文會不會比中文更容易被撐爆。
