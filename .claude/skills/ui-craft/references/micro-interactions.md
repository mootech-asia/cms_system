# Micro-interaction 細節與「這個題材能不能放花俏效果」

## 先回答一個關鍵判斷：這個 repo 可以用比較花俏的互動效果嗎？

`taste-skill` 有一條規則很值得直接拿來用：**scroll 觸發的場景/shader 效果只保留給
「技術性題材」**（軟體、AI、開發工具、電玩遊戲、金融科技、硬體），**一般商家/
服務類網站（咖啡店、診所、工作室）一律只用照片，不放這類效果**——不是因為花俏不好，
是因為花俏的效果只有在題材本身「技術感」夠重的時候才會讀起來像刻意設計，放在賣
咖啡豆的網站上就只會像硬套效果。

**這個 repo 落在「電玩/博弈」＋「金融科技」（儲值/提款）這個被明確列為可以用的
分類裡。** 所以使用者要求的「互動能力/動效要加強」方向，在這個 repo 是站得住腳
的——不是漫無目的地加動畫，是這個題材本來就適合。同一條規則也提醒：不是每個
頁面都要放，單一頁面通常只配一到兩個「記憶點」等級的效果（呼應第二層「一個頁面
只做一個記憶點」），其餘版面還是靠照片/版面本身的構成撐起來，不是每個區塊都疊
特效。

## Hover / 進場的具體數值（兩個來源一致，不是各說各話）

- **卡片 hover**：整張卡片位移 **2px**（輕微上浮，不要位移到看起來像跳走）。
- **圖片 hover**：圖片在自己的容器內縮放 **1.02–1.03 倍**（容器本身不變，圖片
  在裡面稍微放大），不要整個容器跟著放大導致版面跳動。
- **按鈕**：hover 時有「踏一步」的位移感，`:active`／點擊時明確按壓回饋（呼應
  第三層已經有的 `scale(0.97)` 規則，這裡補的是 hover 階段也要有，不是只有
  按下那一刻）。
- **底線型連結**：hover 時底線用動畫「畫出來」，不是直接顯示/消失。
- **卡片輪播型的 loop**（例如遊戲分類卡片裡面的小動畫、促銷卡片的循環展示）：
  一輪 **2.5–4 秒**，hover 時重新從頭開始播放（重複且在 hover 時重啟），不要
  是使用者看不出節奏、隨機跳動的循環。
- **明確禁止**：3D 傾斜（tilt）效果、無目的的走馬燈輪播、定時自動切換的 tab——
  這三種是最常見的「看起來有動但沒有意義」的裝飾性動效，不要加。
- **進場**：每個 hero 區塊只在頁面載入時播放一次進場動畫（不是每次捲動回來都
  重播），頁面上每個主要區塊最多一到兩個「記憶點」等級的動效，其餘維持靜態。

## 變化性的具體自我測試（補第二層/`layout-composition.md` 的「變化性稽核」）

`hallmark` 的「鏡子測試」可以直接拿來用，比光靠感覺判斷更具體：**做完一個版面
決定後，問自己「如果是另一個差不多的頁面/區塊，會不會剛好套出一模一樣的組合？」
如果答案是會，就換掉其中一個決定，並且講出來換了哪一個。** 這跟 `craft-polish-
motion.md` 已有的「互換測試」是同一件事的不同問法，兩個都可以用。

## 兩個 CSS 防呆技巧（avoid 橫向捲動/圖片把版面撐壞）

- **防止橫向捲動用 `overflow-x: clip`，不要用 `overflow-x: hidden`，更不要用
  `100vw`**：`hidden` 在某些情況下會意外吃掉 `position: sticky` 的效果，
  `100vw` 在有捲軸的桌面瀏覽器上會比實際可視寬度寬，兩者都容易在特定情境下
  製造出乎意料的橫向留白/捲動。`clip` 單純裁切，不會有這些副作用。
- **圖片/卡片網格的欄位用 `grid-template-columns` 搭配 `minmax(0, 1fr)`**，不要
  直接寫 `1fr`——沒有 `minmax(0, …)` 的話，欄位內如果放了比預期寬的圖片或長字串，
  grid 容器會被撐寬超出版面；標題類文字搭配 `overflow-wrap: break-word` +
  `min-width: 0`，避免單一過長的字串（遊戲名稱、促銷標題）把整欄撐爆。這跟第五層
  「多語言排版」的「版面要撐得住文字變長」是同一個精神，這裡是更具體的 CSS 寫法。

## 補充幾個生成式介面通病（接續第二層/第四層的清單）

- **連結文字後面黏一個箭頭符號**（「了解更多 →」這種），跟文字之間沒有真正的
  間距與用途，是最常見的「看起來像範本」的裝飾，拿掉箭頭或是說清楚箭頭要做什麼
  （例如真的代表跳轉到外部頁面才需要用圖示，而不是裝飾）。
- **用手繪風格模擬瀏覽器/作業系統視窗外框來包裝截圖**——這種「畫一個假瀏覽器
  外框」的手法是很明顯的範本感來源，截圖本身夠清楚就不需要額外包裝。
- **一句標題裡只把其中一個字用斜體或不同顏色強調**——跟第一層已經講過的
  「hierarchy 靠字重/顏色不是靠突兀的局部強調」是同一條界線，這裡補一個具體
  常見的犯規型態。

## 新文案才適用的提醒（跟第七層同一條界線）

`hallmark` 有具體的字數建議（hero 標題 ≤ 7 個字、一句話說明 ≤ 12 個字、單一畫面
視覺上大約 80 字以內），這些數字是英文計算的，而且**只適用於新寫的 hero/行銷型
文案**，不是拿來「精簡」既有頁面已經寫好的文字——既有內容逐字保留的界線跟
`references/ux-writing.md` 講的是同一條，不要因為看到這幾個數字就把現有頁面的
文案拿去硬砍。
