# 慶祝重做版 V3

重新生成完整人物姿勢，原始六格圖保存在 `celebration/keyposes-original.png`。僅重做慶祝；其他動作與站位不變。

2 秒循環、400×500，48 張輸出 PNG（33 張不同內容；中立停頓有重複），GIF 編碼合併為 41 幀。WebP 與 PNG 保留透明度，GIF 使用深墨綠底供對話預覽。

每個中間幀只取一張完整姿勢的紋理，不進行雙姿勢交叉淡化。平滑映射逐幀檢查 Jacobian 必須大於 0.2，避免先前三角網格折返重複手套紋理。角色高度對齊、頭部與槍身以固定控制點約束。六個生成姿勢依 0、2、3、4、2、0 排列。

技術檢查不等於主觀流暢度認可；正式效果仍以實際播放為準。V1／V2 保留追溯。
