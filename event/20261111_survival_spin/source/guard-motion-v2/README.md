# 桃紅人物動態優化 V2

沿用已接受的角色畫質與呼吸動作基準。沒有建立預覽頁，六段 GIF 直接提供於對話；原遊戲內檔案未由本批替換。

| 動作 | GIF／WebP 檔名前綴 | 內容 |
|---|---|---|
| 呼吸（已獲使用者確認） | idle-breathe-v2 | 胸肩起伏、頭部跟隨，下半身固定 |
| 觀望 | idle-look-v2 | 頭部與軀幹配合左右偏移、停頓與回正 |
| 抬手招呼 | idle-greet-v2 | 手臂抬起示意、身體反向平衡、緩慢收手 |
| 期待 | anticipation-v2 | 雙手收攏，身體略沉與小幅律動 |
| 慶祝 | celebration-v2 | 預備下沉、抬臂小跳、落地緩衝 |
| 失望後恢復 | recover-v2 | 低頭沉肩，抬手恢復與回正 |

每段 PNG／GIF 400×500、48 幀、2000ms；GIF 深綠底保留柔影觀感，WebP 為透明版本，原始 RGBA 幀另存。頭尾使用同一基準幀。這是現有圖層關節與局部形變動畫，不是重新生成的全 3D 動作或高清放大圖。

驗證：`breath-checks.json`、`actions-checks.json` 記錄時長、原始幀外框與共用頭尾；`actions-keyframes.jpg` 提供五段關鍵姿勢。`browser-checks.json` 記錄五段 GIF 的解碼與播放觀察。技術檢查不取代使用者對新動作的視覺評價。

兔比動態及完整品牌包未包含於此批交付。
