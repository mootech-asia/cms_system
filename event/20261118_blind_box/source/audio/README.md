# blind_box（中東神燈寶藏）音訊製作說明

- **作者／工具**：原創程式合成（Python/NumPy；烏德琴/卡農琴/豎琴以 Karplus-Strong 撥弦合成，達布卡/鈴鼓/蘆笛為合成）＋ ffmpeg 母帶。無使用任何第三方取樣或音色庫。
- **授權**：100% 原創、免版稅、可商用，版權歸委託方所有（等同買斷／CC0）。未輸入任何受版權保護曲目作參考（未參考迪士尼《阿拉丁》等）。
- **主題**：中東神燈寶藏（Arabian Nights）＋寶箱；一千零一夜尋寶冒險。
- **背景音樂 bgm**
  - BPM 100、4/4（maqsum 律動）；主色 D Hijaz（Phrygian dominant：D–E♭–F♯–G–A–B♭–C），B 段加亮。
  - 結構 A(8)＋B(10)＋A′(8)＝26 小節；總長 62.4 秒。
  - 配器：烏德琴 oud 主題與撥奏、卡農琴 qanun 快速撥奏、蘆笛 ney、暖弦樂、達布卡 darbuka、鈴鼓 riq、指鈸、魔法時刻的豎琴滑奏與鐘聲。
  - **循環**：無縫循環，頭尾不淡入淡出；tail-wrap；循環點＝檔案頭尾（整數小節、取樣精準，接點量測 0.0）。
  - 響度：−20.1 LUFS（integrated）、真峰 −1.2 dBTP。
  - 無人聲、無吟唱、無弄蛇人笛橋段。
- **特效音**（11 個）：短時響度約 −16 LUFS、彼此一致；真峰 ≤ −1 dBTP；第一個取樣即發聲、尾端自然衰減；單聲道內容。音高落在 D Hijaz 內。開箱音為木蓋嘎吱＋黃銅鎖扣＋金光＋煙霧 whoosh（無精靈人聲）。揭曉四階呈階梯式。
- **技術**：網頁 MP3（bgm 160kbps、sfx 128kbps，44.1kHz）；原始母帶 WAV 48kHz/24-bit。
- **備註**：`tear` 事件的交付檔名為 `open.mp3`（依需求單）。
