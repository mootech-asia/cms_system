# 拆盲盒（20261118_blind_box）

六個盲盒環形排列，左右拖曳或用箭頭挑選 → 選定後橫滑或按按鈕開蓋 → 直接呈現立體寶物（每盒可設 1–5 個，多個時逐件查看並顯示總覽）。
次數、規則、紀錄、跑馬燈、分享、音效、三語系、換圖標籤與內部面板比照 `20261111_lucky_wheel`。

- 入口：`index.html`（免建置）
- 設定與換圖：`assets/js/config.js`；色票：`assets/css/theme.css`
- 共用程式：`../shared/unbox-3d/`（與拆卡包共用，說明見該資料夾 README）
- 美術：`DESIGN_TASKS.md`（需求）、`GPT_ASSET_BRIEF.md`（製作步驟與提示詞）、`DELIVERY_CHECKLIST.md`（交付勾選）
- 內部面板：畫面同一位置連點三下（每下間隔 ≤0.5 秒，點在按鈕上不算）：每次獎品數預覽、重設次數（10）、換圖標籤開關
- 中文預覽：Ctrl+Alt+L（Mac：Control+Option+L）

已套用宇宙卡包／神燈寶箱美術、三語主標、UI、分享圖與六種音效。獎項、次數與紀錄仍為 mock，尚未串接正式後台。可編輯主標與字型授權位於 `source/title/`。


主視覺依 en／ko／th 切換各自 690×240 藝術字圖；中文藝術字僅供內部預覽。宇宙使用切角科技面板，沙漠使用黃銅與羊皮紙圓弧框飾。頁尾波浪裝飾已停用。

資訊區改用獨立主題冊頁：專屬 folio-header 美術、內嵌標題、分段規則與帶獎品圖示的收藏紀錄。分享／音效按鈕使用內嵌 SVG 與主題外框；點擊、靜音叉號、分享展開與鍵盤焦點保留可辨識狀態。舊紀錄不清除，以獎品名稱補查圖示；新紀錄儲存圖示。

## 主題控制元件與效能交付（2026-11-18）

控制圖皆為透明 WebP，動態文案維持 DOM 多語系。主按鈕 900×270、次數銘牌 630×210、左右導覽 192×192、跑馬燈 1000×180；原稿保留於 `source/ui/`。沙漠以黃銅雕刻、綠松石與翡翠琺瑯為主，面板使用 900×300 連續拱形框飾；場景使用 900×300 沙塵體積貼圖、36 片花瓣及 90 條風沙粒子。

動畫在離屏／背景分頁暫停；3D 上限 30 fps、DPR 上限 1.5，靜止寶箱不持續重繪，減少動態偏好保留靜態環境。首屏完成後才預載揭曉卡圖。靜態交付圖經尺寸與 alpha 驗證、容量比較及實際畫面檢查；不可把 `source/` 當成網頁載入資源。測試證據與限制見 `../../docs/event-unbox-jewel/README.md`。
