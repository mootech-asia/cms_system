## 一、美術方向

| 項目 | 方向 |
|---|---|
| 主題 | **中東神燈寶藏（Arabian Nights）**：《一千零一夜》式的沙漠夜晚：黃銅神燈、阿拉伯花紋、馬賽克磁磚、吊燈籠暖光、寶石與金幣。盲盒的概念改成**寶箱**：每個寶箱裡藏著神燈的禮物。**華麗、溫暖、神秘但明亮**。 |
| 色票 | 午夜靛藍 `#1B1446`、沙丘金 `#E8C48A`、黃銅金 `#D4A537`、綠松石 `#2BB5A7`、紅寶石 `#C2334D`、燈籠琥珀 `#FFB547`（交付時填進 `assets/css/theme.css`，見下方「色票」） |
| 空間 | **有角度、有透視的 3D 空間**：背景＋往前延伸的地板，光源統一「前上方偏左」，地板中央有光圈；六個寶箱浮在光圈上方繞圈，接地陰影由程式畫，**素材不畫地面陰影**。 |
| 3D 外型 | 寶箱是程式做的 3D 模型：長方箱身（寬 1.6：高 1.0：深 1.1）＋**半圓拱形箱蓋**（沿後緣掀開）。正面＝`chest-front`、左右與背面＝`chest-side`、拱形蓋面＝`chest-lid`、拱蓋兩端半圓＝`chest-lid-end`。 立體、打光、透視都由程式負責，**交付的是「攤平的平面貼圖」**。 |
| 揭曉 | 深色遮罩上，獎品卡從卡背翻到正面，後方放射光＋依稀有度變色的光暈；最高稀有度明顯更華麗。 |
| 版面（第一屏） | 主標 → 活動期間 → 3D 環形（左右箭頭；點選任意一個就是選擇）→ 剩餘次數 → 點選提示（選定後變成主按鈕）→ 跑馬燈。手機 360×640 起第一屏看得到；只用 H5 寬度（480px 置中）。 |
| 吉祥物動態 | **暫緩**：頁面目前不放會動的吉祥物。 |

### 禁止元素（出現任一項即退回）

- **迪士尼《阿拉丁》的任何元素**：角色（阿拉丁、茉莉、藍色精靈、賈方、猴子、鸚鵡、老虎、有表情的飛毯）、阿格拉巴王宮輪廓、奇蹟洞的老虎頭、片名字體與標誌。改名不等於原創，只取《一千零一夜》民間故事的共通元素（神燈、寶藏、沙漠夜晚）。
- **宗教符號與文字**：不可有阿拉伯文書法或任何可讀文字、星月旗徽記、清真寺宣禮塔等宗教建築特徵；天上的月亮可以畫，但不要做成徽章。
- 刻板化或醜化特定民族、服飾。
- 任何文字、數字、中文。

### 語系規則（嚴格）

- 前台語系：英文／韓文／泰文，預設英文。**所有交付圖檔不得出現中文字。**
- 需要文字的圖只有活動主標（每個語系一張）；按鈕、標籤、彈窗、包裝上一律不放文字，由程式疊字。
