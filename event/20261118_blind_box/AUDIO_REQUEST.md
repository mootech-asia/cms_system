## 一、風格總則

- **主題**：中東神燈寶藏（Arabian Nights）＋寶箱
- **關鍵字**：溫暖、華麗、神秘冒險、尋寶、魔法金光
- **禁止**（出現任一項即退回）：迪士尼《阿拉丁》任何歌曲（含其旋律輪廓、和聲進行與招牌配器段落）、宗教性的人聲吟唱或喚拜（adhan）類聲音、刻板化的「弄蛇人笛」橋段、過度誇張的肚皮舞夜店風、任何人聲與歌詞、可辨識的知名曲目取樣。
- 背景音樂與全部特效音要**同一個聲音世界**：同一套音色家族、同一個調性中心（特效音的音高落在背景音樂的調內），聽起來像同一支作品。
- 活動前台是英文／韓文／泰文多語系，**全部音檔不放人聲、歌詞或旁白**。

## 二、背景音樂（bgm）

| 項目 | 規格 |
|---|---|
| 風格 | **《一千零一夜》式的尋寶冒險配樂**（Middle-Eastern inspired adventure）：沙漠夜晚的宮殿中庭，燈籠搖曳、寶箱閃金光——溫暖、華麗、帶點神秘與俏皮的探險感。 |
| 速度與拍號 | 96–108 BPM；節奏以 maqsum（4/4）或 baladi 為基礎 |
| 調性 | D Hijaz（Phrygian dominant，D–E♭–F♯–G–A–B♭–C）為主色，B 段可轉到 D 大調或 G 小調讓情緒明亮；不要全曲陰暗 |
| 配器 | 烏德琴 oud（主旋律／節奏撥奏）、卡農琴 qanun（閃亮的快速撥奏與滑音）、蘆笛 ney（氣聲旋律，少量）、溫暖的弦樂（持續音＋短奏 ostinato）、達布卡鼓 darbuka、鈴鼓 riq、框鼓、少量指鈸；魔法時刻用豎琴滑奏＋鐘聲閃光 |
| 結構 | A 段 8 小節（烏德琴主題＋達布卡）→ B 段 8 小節（卡農琴與弦樂加入、能量稍高）→ A′ 8 小節（回主題、收回）→ 無縫回到開頭；總長 60–90 秒 |
| 旋律 | 主旋律以烏德琴或蘆笛演奏，簡單好記，用 Hijaz 的增二度音程做出中東色彩；不要人聲、不要歌詞、不要吟唱 |
| 能量 | **中低**：它是背景，要讓位給特效音。2–5 kHz 不要堆滿（特效音的鐘聲、閃光都在這一段），低頻在手機喇叭上不可糊成一團 |
| 循環 | **無縫循環**：頭尾不淡入淡出；把最後一小節的殘響尾巴疊回開頭（tail wrap），循環點對齊小節線、取樣精準，連播三遍聽不出接縫 |

## 三、特效音（全部單聲道或窄立體聲，頭部不留空白）

| 名稱 | 交付檔名 | 長度 | 什麼時候播 | 聲音設計 |
|---|---|---|---|---|
| `click` | `click.mp3` | ≤0.15 秒 | 一般按鈕 | 小巧的**黃銅輕敲**或指鈸「叮」 |
| `move` | `move.mp3` | ≤0.25 秒 | 環形轉一格（拖曳、箭頭） | **沙漠微風拂過**的 whoosh＋一點小鈴聲 |
| `select` | `select.mp3` | ≤0.4 秒 | 點選一個寶箱＝選定 | **寶箱鎖扣晃動**的金屬聲＋短促金色閃光音 |

| `reveal-common` | `reveal-common.mp3` | 0.5–0.8 秒 | 揭曉：{r} | 單一聲**卡農琴撥奏**＋小鈴 |

| `reveal-epic` | `reveal-epic.mp3` | 0.9–1.3 秒 | 揭曉：超稀有（寶物出現在台座上） | 用 **Hijaz 音階快速上行**的卡農琴刮奏＋閃光 |
| `reveal-legendary` | `reveal-legendary.mp3` | 1.5–2.0 秒 | 揭曉：最高級（Secret 隱藏款，寶物出現在台座上） | **神燈魔法**：煙霧盤旋上升的 whoosh → 豎琴滑奏 → 金光爆發 → 金幣叮噹的尾音；整組最華麗 |
| `reward` | `reward.mp3` | 0.8–1.2 秒 | 多個總覽（後台設定每箱多個時才會用到） | 卡農琴琶音＋金幣聲收尾 |
| `collect` | `collect.mp3` | ≤0.8 秒 | 收下獎勵（關閉揭曉） | **一把金幣落入錢袋**的叮噹聲 |
| `error` | `error.mp3` | ≤0.3 秒 | 次數用完、尚無獎項 | **悶悶的木頭敲擊**（像箱子鎖住打不開）；不可用蜂鳴器或警報聲 |

- 揭曉的四個稀有度要聽得出**階梯感**：普通 < 稀有 < 超稀有 < 最高級，越高越華麗、越長；同一組音色延伸，不要四種風格。
- 每個特效音**第一個取樣就發聲**（不要前置靜音），尾巴自然衰減到靜音，不要硬切。
