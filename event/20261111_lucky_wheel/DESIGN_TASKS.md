## 製作優先級（照順序做，先快速掌握整體設計質感）

| 級別 | 定義 | 做法 |
|---|---|---|
| **P0 全局視覺** | 面積大、決定第一眼的整體質感，且製作相對直接 | **最先做**。全部 P0 到位後先整頁截圖確認整體方向，再往下做 |
| **P1 版面元件** | 主要版面與互動元件 | P0 確認後接著做 |
| **P2 細節** | 小圖示、裝飾、設定調整 | P1 之後 |
| **P3 精修與動態** | 複雜、需要時間打磨的項目（吉祥物動態、角色設定圖、原始檔、音效、影片） | **放最後慢慢雕出品質**；需要時可先交靜態「假圖」讓頁面先成形（假圖不打勾，正式版交付才打勾） |

勾選表每列最後一欄是優先級；檢查腳本會顯示各級進度（例：`P0 3/11`）。

本活動的順序：
- **P0**：`stage-bg`、`stage-bg-desktop`、`stage-floor`、`title-en/ko/th`、`wheel-frame`、`wheel-stand`、`pointer`、`btn-go`、扇區色票

## 一、美術方向

| 項目 | 方向 |
|---|---|
| 整體氛圍 | 彩色、喜慶；西式百老匯現代舞台；簡潔、乾淨、明亮；整體色調**暖而舒適** |
| 轉盤 | 彩色扇區，參考博弈遊戲轉盤：金色外框、燈泡圈、立體光澤、中央按鈕 |
| 舞台 | **有角度、有透視的 3D 舞台世界觀**（不要正面平面）：木地板往後延伸、有透視線與縱深，兩側布幕／側牆往內收，後方拱門或背牆，聚光燈在地板打出光圈；轉盤立在舞台後方、兔比站在地板上，光源方向與陰影一致。可用單點透視（消失點在畫面中上）或略帶角度的兩點透視，但轉盤所在的中央區域要正面、清楚。背景要亮，不要暗黑夜店風 |
| 真實空間感 | 所有元素都在同一個 3D 舞台裡：**轉盤立在金色底座上、底座踩在地板**；**兔比站在轉盤前方的地板上**（離觀眾較近、所以顯得較大；只擋到轉盤右下角外框一小塊，約 3% 盤面，不可擋到盤面文字與中央按鈕）；光源統一為「前上方偏左」的舞台聚光燈，轉盤、底座、兔比的受光面與陰影方向一致；接地陰影由程式加在底座與兔比腳下，**素材本身不要畫地面陰影**（避免雙重陰影） |
| 版面（第一屏） | 由上到下：主標 → 活動期間 → 轉盤（立在底座上）→ **操作台**（中獎跑馬燈＋剩餘次數＋Spin now 大按鈕）；兔比站在操作台後方、轉盤右前方。手機 360×640 起、桌機 1280×720 起，第一屏就能看到轉盤與整個操作台，不用往下捲。 |
| 人物 | **不要主持人**。只有吉祥物兔子（見第四節） |
| 版面 | 上半＝轉盤遊戲（舞台）；下半＝活動規則空位（文字由我們的後台填寫，不做成圖） |

### 語系規則（嚴格）

- 前台語系：**英文 / 韓文 / 泰文**，預設英文。
- **所有交付圖檔不得出現中文字。**（中文只在內部編輯預覽使用，老闆與客戶不會看到）
- 需要文字的圖（目前只有活動主標）**每個語系各出一張**；其他圖一律**不含文字**，文字由程式疊上去，才能換語系。

## 二、交付規格（共通）

- 設計稿基準寬度 **750px**（手機），頁面實際以 2 倍圖顯示；請照下表「外框尺寸」輸出（含留白），程式依外框比例定位，尺寸不同會跑版。
- 除背景外全部**去背**。靜態圖：PNG / WebP / SVG 皆可；吉祥物：GIF（見第四節）。
- 單張靜態圖建議 ≤ 300KB，背景 ≤ 500KB，每個 GIF 建議 ≤ 1.5MB。
- 替換方式：**同檔名覆蓋**；若改用 PNG/WebP，把 `assets/js/config.js` 裡對應路徑改成新檔名即可。

### 盤面配色（不是圖，是色票）

盤面扇區由程式依後台填的獎項數量（3～12 項）自動畫出，所以**不需要畫盤面圖**，請提供：

- **6 組扇區色**（依序循環），每組含「底色」與「該底色上的文字色」。目前佔位色：紅 `#E5484D`、金 `#F7B733`、桃紅 `#E5468F`、橘 `#FF8A3D`、青綠 `#23A99A`、紫 `#7A5AF0`。
- 分隔線顏色（目前金色 `#F2B53A`）。
- 色票填在 `assets/css/event.css` 開頭的 `--ev-wheel-1` ～ `--ev-wheel-6`。

### GIF 規格

- 畫布 **400 × 500 px**（每一幀相同尺寸、角色腳底位置固定，避免切換狀態時跳動）。
- **用連續圖（序列幀）製作**，幀數盡量多以求流暢：建議 **24 fps**；待機每段 2～3 秒（48～72 幀）、抽獎中 1～2 秒循環（24～48 幀）、發表結果 2 秒（48 幀）。
- **共用基準幀（必守）**：先做一張基準姿勢 `mascot/base-frame.png`（400×500、透明，正面自然站姿）。**每個 GIF 的第一幀與最後一幀都必須是這張**，動作從它開始、回到它結束 → 每段都能無縫循環，頁面也能在任何一輪結束時隨時切換動作而不跳格。
- **每段長度相同**：一律 48 幀、24fps（2 秒）；程式以這個長度判斷一輪何時結束再切換。
- **鏡頭固定**：不可有整體縮放（zoom）或整隻角色忽大忽小；除了動作本身的手腳、耳朵位移外，身體外輪廓大小要維持一致。
- 去背透明。GIF 只有 1-bit 透明，毛髮邊緣容易出現白邊／鋸齒：請以舞台背景的暖色（約 `#FFE6CC`）作為邊緣去背底色（matte）輸出。
- 同時交付**原始 PNG 序列幀**（含 alpha）備存，日後若要改成 APNG / WebP 動圖可直接轉出。
- 顯示位置：站在轉盤前方的舞台地板上，只擋到轉盤右下角外框一小塊（約 3% 盤面）；畫布顯示寬度約為內容欄的 95%（手機約 340px、桌機約 425px），角色寬約 200px（手機）。
- **角色在畫布中要大**：佔畫布寬約八成、腳底貼近畫布下緣（目前交付版只佔約六成）。
- 光源與舞台一致（前上方偏左），**不要畫地面陰影**（程式會加接地陰影）。
