# 20261111_lucky_wheel 設計需求任務清單

目前頁面是 mock up：版面、抽獎流程已可運作，所有圖片都是佔位圖（圖上印有檔名與尺寸）。
設計只要依下表交付圖檔，放進 `assets/img/` 即可完成活動，不需要動程式。

## 替換方式

1. **同檔名覆蓋**：交付 SVG 時直接覆蓋 `assets/img/` 下同名檔案。
2. **改用 PNG / WebP**：檔案放進 `assets/img/`，再把 `assets/js/config.js` 裡 `images`（或 `prizes[].icon`）對應路徑改成新檔名。
3. 獎項名稱、數量、機率、免費次數、彈窗標題都在 `assets/js/config.js` 修改。

## 共通規格

- 設計稿基準寬度 **750px**（手機），頁面實際最大寬度 480px，以 2 倍以上圖輸出確保高解析螢幕清晰。
- 除背景外，所有圖片**去背**（透明 PNG / WebP / SVG）。
- 單張圖建議 ≤ 300KB；背景 ≤ 500KB。
- 尺寸請**照下表外框尺寸輸出**（含留白），程式依外框比例定位，尺寸不同會跑版。

## 盤面兩種做法（擇一，請在交付時說明）

- **A. 程式疊字（目前預設，`showLabels: true`）**：盤面只畫扇區底色與分隔線，獎項文字＋圖示由程式疊上。之後改獎項不必重出盤面圖。
- **B. 文字畫進圖（`showLabels: false`）**：獎項文字、圖示直接畫在盤面圖裡，視覺自由度高；但改獎項就要重出圖。交付後把 `config.js` 的 `showLabels` 改為 `false`。
