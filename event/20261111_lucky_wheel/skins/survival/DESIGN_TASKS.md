## 一、活動定位與命名

- 風格：**生存遊戲秀**——高壓又童趣的遊戲現場：鮮豔桃紅配深墨綠、童年遊戲場、樓梯迷宮、倒數計時、號碼牌。整體要「一看就是那種生存遊戲的氛圍」，但所有圖都是**原創**。
- 活動名稱（主視覺文字）：英 `SURVIVAL SPIN`／韓 `서바이벌 스핀`／泰 `สปินเอาตัวรอด`（文案要改先提三語給我們確認）。
- 角色：**兔比（Moo Rabbit）**，穿桃紅色遊戲工作人員連身服（見第四節）。

### 禁止元素（交付會逐項檢查，有就退回）

- 任何影視作品的**名稱、標誌、字體 Logo**（不得出現「Squid Game」「오징어 게임」等字樣或仿製字型）。
- **○△□ 三個符號的組合**（面罩、胸章、按鈕、圖示、底紋都不行）；單獨的圓形、方形、三角形當作一般幾何裝飾可以，但不可三個並排成一組。
- **黑色全罩式面罩**、**巨型娃娃**、**綠色運動服＋白色號碼**的玩家造型、劇中特定場景的完整重現。
- 血腥、死亡、槍械、淘汰暗示（本活動是開心的抽獎）。
- 中文字（所有圖一律不得出現中文；需要文字的只有主標，三語各一張）。

## 二、美術方向

2026-11-12 方向補充：大量參考《魷魚遊戲》的粉彩樓梯迷宮、桃紅與深墨綠對比、童趣空間與規律秩序的反差；提高場景辨識度與空間縱深。活動主標、品牌角色與場景配置維持自有設計，第一節禁止元素仍適用。

| 項目 | 方向 |
|---|---|
| 色票 | 桃紅 `#E8327C`（主色）、亮粉 `#FF6FA8`、深墨綠 `#06231F`／`#0F6B5F`、薄荷綠 `#36B39B`、米白 `#F3E9D2`、黑 `#1D1D1F`。目前 mock 用這組，可微調後在 `skin.css` 交付 |
| 舞台 | **有透視、有縱深的 3D 遊戲大廳**：深墨綠挑高空間，兩側是桃紅／亮粉的**樓梯迷宮牆**往後延伸，後方拱門或大型倒數螢幕（螢幕只畫外框與發光，**不放數字**），地板是有透視線的拋光地磚。轉盤立在大廳中央，兔比站在地板上 |
| 光源 | 前上方偏左的舞台聚光燈，光色帶一點粉；轉動時四周壓暗、聚焦轉盤 |
| 元件 | 圓角、粗黑外框＋桃紅填色的「遊戲 UI」感（像遊戲機台按鈕），米白紙卡、號碼牌、打孔票根、椪糖糖餅（只用糖餅外形與壓紋，不做○△□壓紋） |
| 氛圍 | 刺激但可愛、乾淨、明亮度足夠（不要陰暗恐怖） |
| 版面 | 只用 H5 寬度（480px 置中），背景以手機版 750×1000 為準 |

## 四、兔比：遊戲工作人員造型（P3）

- **服裝**：桃紅色連身工作服（拉鍊、腰帶、袖口收緊），黑色工作手套與短靴；胸前一個**我們自己設計的徽章**（例：MOOTECH 標誌、轉盤圖形、兔耳輪廓，**不可○△□**），手臂或胸口可掛號碼牌（例：`M-001`）。
- **頭部**：**不戴面罩、臉完整露出**；保留兔比招牌墨鏡與耳機（品牌識別），長耳朵從連帽兩側穿出或不戴帽。
- **品質與一致性**：與 `../../reference/` 的熊北四視圖、`brand/moo-rabbit/` 的兔比設定同一套渲染品質；背心換成連身服，其餘臉型、毛色、配件不變。
- **動態 6 段**（規格同預設皮的 2026-11-12 重做要求：48 幀、2000ms、頭尾＝基準幀、任何一幀不可貼邊、影子畫進角色、主交付為 RGBA PNG 序列幀）：
  待機 ×3、期待（轉動中）、慶祝（中獎）、失望（未中獎）。
- 交付位置：`img/mascot/base-frame.png`、`img/mascot/<狀態>.gif`、`source/mascot-frames/<狀態>/frame_001.png`～`frame_048.png`。
- 未交付前頁面暫用預設皮的兔比（穿背心），這是佔位，不代表定稿。

## 五、交付方式

1. 檔案放到本資料夾 `img/`（吉祥物放 `img/mascot/`），**同檔名覆蓋並刪掉 `.svg` 佔位檔**；副檔名不同時改 `../../assets/js/config.js` 的 `skins.survival.images` 路徑。
2. 色票改 `skin.css`。
3. commit → 在 `DELIVERY_CHECKLIST.md` 打勾填 commit → 執行
   `python3 scripts/check_delivery.py event/20261111_lucky_wheel/skins/survival/DELIVERY_CHECKLIST.md`，已打勾的列必須全部 OK。
4. 附上 `?skin=survival` 的待機／轉動／開獎三張截圖，以及三語主標並排圖。
