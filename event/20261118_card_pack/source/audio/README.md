# card_pack（宇宙幻象）音訊製作說明

- **作者／工具**：原創程式合成（Python/NumPy 加法與 Karplus 合成）＋ ffmpeg 母帶（loudnorm／resample／編碼）。無使用任何第三方取樣或音色庫。
- **授權**：100% 原創、免版稅、可商用，版權歸委託方所有（等同買斷／CC0）。未輸入任何受版權保護曲目作參考。
- **主題**：宇宙幻象（Cosmic Illusion）＋兔比宇宙兔女郎；夢幻電子（dreamy synth-pop／space lounge）。
- **背景音樂 bgm**
  - BPM 104、4/4；調性 F 大調（含 Lydian 升四級色彩），無小調陰暗段。
  - 結構 A(8)＋B(8)＋A′(8)＋回頭(4)＝28 小節；總長 64.6 秒。
  - 配器：類比合成琶音、暖 pad、鋼片琴/玻璃鐘琴主旋律、豎琴滑奏、電鋼琴、半速軟鼓、sub bass、星光點綴。
  - **循環**：無縫循環，頭尾不淡入淡出；最後一小節殘響已 tail-wrap 疊回開頭；循環點＝檔案頭尾（整數小節、取樣精準，接點量測 0.0）。
  - 響度：−20 LUFS（integrated）、真峰 −3.1 dBTP。
- **特效音**（12 個）：短時響度約 −16 LUFS、彼此一致；真峰 ≤ −1 dBTP；第一個取樣即發聲、尾端自然衰減；單聲道內容（手機單喇叭相容）。音高落在 F 大調內，與 BGM 同一聲音世界。揭曉四階 common<rare<epic<legendary 呈階梯式漸強漸長。
- **技術**：網頁 MP3（bgm 160kbps、sfx 128kbps，44.1kHz）；原始母帶 WAV 48kHz/24-bit。
