## 一、風格總則

- **主題**：宇宙幻象（Cosmic Illusion）＋兔比宇宙兔女郎（宇宙舞台的主持人／魔術師助手）
- **關鍵字**：夢幻、發光、閃爍、魔術秀、漂浮感、明亮好奇
- **禁止**（出現任一項即退回）：恐怖或陰森的暗黑氛圍、冷硬機械的工業／太空戰爭音效、史詩預告片式銅管轟炸、重低音 drop（dubstep 類）、雷射槍與警報聲、任何知名太空電影或遊戲主題曲的旋律或招牌音色。
- 背景音樂與全部特效音要**同一個聲音世界**：同一套音色家族、同一個調性中心（特效音的音高落在背景音樂的調內），聽起來像同一支作品。
- 活動前台是英文／韓文／泰文多語系，**全部音檔不放人聲、歌詞或旁白**。

## 二、背景音樂（bgm）

| 項目 | 規格 |
|---|---|
| 風格 | **宇宙魔術秀的夢幻電子樂**（dreamy synth-pop／space lounge）：像在星雲中的舞台看一場輕快的魔術表演——閃閃發亮、帶點俏皮，不是冷冰冰的太空科幻。 |
| 速度與拍號 | 100–108 BPM，4/4 |
| 調性 | 大調為主（建議 F 大調），可用 Lydian（升四級）營造夢幻感；避免小調陰暗段落 |
| 配器 | 柔和的類比合成器琶音（十六分音符，帶濾波起伏）、溫暖的 pad 鋪底、玻璃質感的鐘琴／鋼片琴（celesta）旋律、豎琴滑奏（魔術時刻）、輕柔電鋼琴和弦、半速律動的軟鼓（彈指、輕拍手、柔和的大鼓）、溫和的 sub bass；點綴星光閃爍音效（sparkle） |
| 結構 | A 段 8 小節（建立氛圍與主旋律）→ B 段 8 小節（加入節奏與豎琴、能量稍高）→ A′ 8 小節（回主旋律、收回能量）→ 無縫回到開頭；總長 60–90 秒 |
| 旋律 | 主旋律要簡單好記、音域不寬（像音樂盒），以鐘琴／鋼片琴為主；不要人聲、不要歌詞、不要人聲取樣（多語系活動） |
| 能量 | **中低**：它是背景，要讓位給特效音。2–5 kHz 不要堆滿（特效音的鐘聲、閃光都在這一段），低頻在手機喇叭上不可糊成一團 |
| 循環 | **無縫循環**：頭尾不淡入淡出；把最後一小節的殘響尾巴疊回開頭（tail wrap），循環點對齊小節線、取樣精準，連播三遍聽不出接縫 |

## 三、特效音（全部單聲道或窄立體聲，頭部不留空白）

| 名稱 | 交付檔名 | 長度 | 什麼時候播 | 聲音設計 |
|---|---|---|---|---|
| `click` | `click.mp3` | ≤0.15 秒 | 一般按鈕 | 清脆的**水晶／星星輕敲**一聲，高頻乾淨、不刺耳 |
| `move` | `move.mp3` | ≤0.25 秒 | 環形轉一格（拖曳、箭頭） | 輕柔的**流星掠過聲**（soft whoosh）＋尾端一點星光閃爍 |
| `select` | `select.mp3` | ≤0.4 秒 | 點選一包＝選定 | **魔術棒一點**的「叮」＋閃光粒子音，像兔女郎魔術師揮棒；要有「被選中」的確定感 |
| `tear` | `tear.mp3` | 0.6–0.9 秒 | 撕開卡包 | **全息鋁箔包裝被撕開**的真實撕裂聲（前 0.3 秒）＋撕開瞬間湧出的**星塵閃光**（後段）；不可做成爆炸 |
| `flip` | `flip.mp3` | ≤0.3 秒 | 翻卡 | 卡片翻面的「咻」＋一點星塵尾音 |
| `reveal-common` | `reveal-common.mp3` | 0.5–0.8 秒 | 揭曉：普通 | 單一顆**柔和星星鐘聲** |
| `reveal-rare` | `reveal-rare.mp3` | 0.7–1.0 秒 | 揭曉：稀有 | 兩個音上行的明亮鐘聲＋短閃爍 |
| `reveal-epic` | `reveal-epic.mp3` | 0.9–1.3 秒 | 揭曉：超稀有 | 上行琶音（鐘琴＋合成器）＋星雲般的 pad 膨脹 |
| `reveal-legendary` | `reveal-legendary.mp3` | 1.5–2.0 秒 | 揭曉：最高級（Legendary） | **超新星**：0.5 秒上升膨脹 → 明亮的閃光爆發（不刺耳、不轟炸）→ 長長的星光閃爍尾音；整組最華麗 |
| `reward` | `reward.mp3` | 0.8–1.2 秒 | 多張總覽（後台設定每包多張時才會用到） | 一串星光琶音收尾 |
| `collect` | `collect.mp3` | ≤0.8 秒 | 收下獎勵（關閉揭曉） | 閃光粒子**被收進口袋**的「咻—叮」，上揚、滿足 |
| `error` | `error.mp3` | ≤0.3 秒 | 次數用完、尚無獎項 | 柔和的低音「噗」，像**星星暗下去**；不可用蜂鳴器或警報聲 |

- 揭曉的四個稀有度要聽得出**階梯感**：普通 < 稀有 < 超稀有 < 最高級，越高越華麗、越長；同一組音色延伸，不要四種風格。
- 每個特效音**第一個取樣就發聲**（不要前置靜音），尾巴自然衰減到靜音，不要硬切。

## 七、驗收

- 在活動頁實際播放：背景音樂連播三遍聽不出接縫；開封時壓低後特效音清楚；手機喇叭與耳機各聽一次。
- 逐一觸發每個特效音（選定、撕開／開箱、翻卡、四種稀有度揭曉、收下、次數用完），確認風格一致、音量一致、沒有爆音。
- 對照第一節「禁止」逐項檢查。

## BGM 交付狀態（refine2）

`assets/audio/bgm.mp3` 已提供原創循環配樂；可編輯音符與 WAV 在 `source/audio/`。其餘分項音效仍依本文件原狀態。瀏覽器播放與音量控制已驗證，實機喇叭聽感尚未驗證。
