## 一、美術方向

| 項目 | 方向 |
|---|---|
| 主題 | **宇宙幻象（Cosmic Illusion）**：深空藍紫的星雲、全息虹彩、星光與光環，像在宇宙中漂浮的魔術舞台。**夢幻、發光、明亮**，不要恐怖、陰森或冷硬的科幻機械感。 |
| 色票 | 深空藍 `#0D0B2E`、星雲紫 `#5B2A86`、霓虹洋紅 `#D94FD8`、星光青 `#3FD8FF`、星芒金 `#FFD36B`、全息白 `#F4F1FF`（交付時填進 `assets/css/theme.css`，見下方「色票」） |
| 空間 | **有角度、有透視的 3D 空間**：背景＋往前延伸的地板，光源統一「前上方偏左」，地板中央有光圈；六個卡包浮在光圈上方繞圈，接地陰影由程式畫，**素材不畫地面陰影**。 |
| 3D 外型 | 卡包是程式做的 3D 薄包（放大 1.5 倍顯示）：正面＝`pack-front-*`、背面＝`pack-back`、上下封條＝`pack-crimp`；側邊厚度約 1mm，只用色票上色。 立體、打光、透視都由程式負責，**交付的是「攤平的平面貼圖」**。 |
| 揭曉 | 深色遮罩上，獎品卡從卡背翻到正面，後方放射光＋依稀有度變色的光暈；最高稀有度明顯更華麗。 |
| 版面（第一屏） | 主標 → 活動期間 → 3D 環形（左右箭頭；點選任意一個就是選擇）→ 剩餘次數 → 點選提示（選定後變成主按鈕）→ 跑馬燈。手機 360×640 起第一屏看得到；只用 H5 寬度（480px 置中）。 |
| 吉祥物動態 | **暫緩**：頁面目前不放會動的吉祥物。兔比宇宙兔女郎先出現在卡包正面與分享圖上（靜態插圖）。 |

### 禁止元素（出現任一項即退回）

- **性感化**：不可有連身緊身衣／高衩、網襪、強調胸部或身體曲線、挑逗姿勢；維持兔比原本 Q 版比例與毛絨質感，闔家觀看等級。
- **特定雜誌的兔女郎商標與招牌造型**：不可出現兔頭標誌，也不可使用「黑色緞面連身衣＋白色立領＋袖口＋領結＋白色棉尾巴」這一整組招牌組合。改用宇宙主題的**舞台主持／魔術師助手**服裝（見第四節）。
- 其他作品的角色、星艦、徽章或標誌（任何動畫、電影、遊戲的宇宙題材元素）。
- 任何文字、數字、中文。

### 語系規則（嚴格）

- 前台語系：英文／韓文／泰文，預設英文。**所有交付圖檔不得出現中文字。**
- 需要文字的圖只有活動主標（每個語系一張）；按鈕、標籤、彈窗、包裝上一律不放文字，由程式疊字。

## 四、角色：兔比・宇宙兔女郎造型（P0-A，最先做）

依專案「人物美術製作順序」：新造型**先交完整角色設定圖、審核通過後**才做卡包正面、分享圖等有角色的圖；單張正面圖不能代替設定圖。

- **基礎**：官方兔比（`brand/moo-rabbit/` 品牌包；現有 3D 形象參考 `event/20261111_lucky_wheel/assets/img/mascot/`）。臉、耳朵、毛色、Q 版比例、毛絨質感、招牌配件（科技墨鏡、耳機、MOOTECH 背心標誌的品牌規則）**不可改**，只換服裝與道具。
- **造型方向**：宇宙舞台的**主持人／魔術師助手**——星雲漸層的短披風或燕尾外套、發光領結（星雲色）、耳朵上的星星髮飾、全息手套、一扇發光卡牌或星星魔杖；服裝上有星座點綴與行星光環元素。可愛、自信、帶一點舞台魅力。
- **不可**：見第一節「禁止元素」（不性感化、不用特定雜誌兔女郎的招牌組合）。
- **設定圖內容**（一張 2400×1350，`source/character/cosmic-bunny-sheet.png`）：正面／四分之三側／側面／背面四視圖、與原版兔比並排的身高比例、表情 ×4（開心、驚喜、眨眼、期待）、服裝材質特寫（披風、領結、手套、髮飾）、色票。`source/character/README.md` 寫明服裝構成與色碼。
- 驗收：與原版兔比並排一眼認得出是同一隻；縮到卡包正面大小（約 200px 寬）仍辨識得出；放大檢查背心標誌與配件拼字。
